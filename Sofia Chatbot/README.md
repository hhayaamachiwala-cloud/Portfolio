# Sofia - Women's Safety AI Chatbot 🛡️

Live Project: [Sofia_Ai](https://arshi9214.github.io/Sofia_Ai/)

An empathetic, intelligent, and multilingual AI chatbot designed specifically to support women's safety, especially in Mumbai.

## ✨ Key Features

- 24/7 Emergency Assistance
  - Quick SOS buttons (Police 100, Women Helpline 1091, etc.)
  - Location sharing with trusted contacts
  - Nearest police station finder

- Safety Resources
  - Safe routes recommendations
  - Self-defense tips
  - Legal rights information

- Multilingual Support
  - English
  - Hindi
  - Marathi

- Progressive Web App (PWA)
  - Installable on mobile
  - Works offline
  - Voice input support

- Culturally sensitive and empowering responses

## 🛠️ Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- AI/Chat Logic: Custom JavaScript-based conversational engine
- PWA Features: Service Workers, Manifest
- Responsive Design: Mobile-first

## 🎯 Purpose

To provide immediate, accessible, and discreet help to women in distress while promoting safety awareness.
