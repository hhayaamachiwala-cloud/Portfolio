# HAJA Notes 📝

Android Notes Application built with Android Studio

A clean, secure, and feature-rich notes app with biometric protection, multi-language support, and modern UI.

## ✨ Key Features

- Biometric Authentication (Fingerprint / Face / PIN)
- Create, edit, search, and organize notes
- **Topics / Categories** system for better organization
- Markdown support
- Image attachment (Camera + Gallery)
- Voice input support
- Multiple themes (Blue, Green, Purple, Orange, Red)
- Multi-language support (English, Urdu, Hindi, and more)
- Share notes via WhatsApp, Email, Bluetooth, Quick Share, etc.
- Backup & Restore functionality
- Delete notes / Delete all option

## 🛠️ Tech Stack

- Language: Java
- UI/Layout: XML
- Database: SQLite
- IDE: Android Studio
- Security: Android Biometric API
- Other: Material Design, Voice Recognizer, Image Picker, Share Intent
