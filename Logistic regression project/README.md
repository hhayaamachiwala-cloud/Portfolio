# Logistic Regression Project

Binary Classification Implementation

A comprehensive Jupyter Notebook project demonstrating end-to-end implementation of Logistic Regression for binary classification tasks.

- Data loading and exploration
- Data preprocessing and cleaning
- Feature engineering
- Model training (Logistic Regression)
- Performance evaluation (Accuracy, Precision, Recall, F1, ROC-AUC, Confusion Matrix)
- Visualizations (Seaborn & Matplotlib)
- Model interpretation
