# AdSales Forecast 📈

Advertising Budget Sales Prediction Dashboard

An interactive Streamlit web application that trains multiple Machine Learning models on advertising data and provides sales forecasting with rich visualizations.

## ✨ Key Features

- Model Comparison** of 5 regression algorithms
- Best Performing Model: Gradient Boosting (R² = **0.9370**)
- Interactive dashboard with 4 tabs:
  - Overview
  - Models Comparison
  - Visualizations (Histograms, Scatter, Heatmap, Pair plots, etc.)
  - Real-time Prediction
- Sliders for TV, Radio, Newspaper budget + previous sales

## 🛠️ Tech Stack

- Framework: Streamlit
- ML: scikit-learn (Gradient Boosting, Random Forest, SVR, Linear Regression, Decision Tree)
- Visualization: Plotly, Matplotlib, Seaborn
- Data: Pandas, NumPy
